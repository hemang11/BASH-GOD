# Support

BASH_GOD is a local command catalog and terminal tool. It can help an operator find, inspect, and
review a native command, but it does not replace the native CLI, an environment's access controls,
or the operating procedures for production infrastructure.

## Report a bug

Use the [bug report form](https://github.com/hemang11/BASH-GOD/issues/new?template=bug_report.yml) for reproducible behavior in the
catalog, search, rendering, picker, installer, or managed update/removal flow. Include the BASH_GOD
version, OS and architecture, shell, terminal or SSH context, installation method, and the smallest
reproduction you can provide.

Do not include credentials, tokens, private hostnames, customer data, production payloads, or full
environment dumps. Redact command output before posting it.

## Get help with a command

BASH_GOD shows native commands for review; the native tool's documentation remains authoritative for
its flags, permissions, and operational effects. For a catalog correction or new command, start with
the [contribution guide](CONTRIBUTING.md).

## Scope

The project does not provide managed infrastructure support, cluster access, or a guarantee that a
catalog command is appropriate for a particular environment. Review the command, its compatibility
label, and your local procedures before running it.
